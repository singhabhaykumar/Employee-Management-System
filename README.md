## 📌 Overview

The **Banking Management System** is a console-based application developed in **C++** using **Object-Oriented Programming (OOP)** principles.  

This project simulates real-world banking operations such as account creation, deposit, withdrawal, and account search through a menu-driven interface.

---

## ✨ Features

✅ Create New Account  
✅ Display All Accounts  
✅ Search Account by Account Number  
✅ Deposit Money  
✅ Withdraw Money (with balance validation)  
✅ Menu-Driven Interface  
✅ Dynamic Account Storage using STL Vector
